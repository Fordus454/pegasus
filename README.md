Most tools are stand alone apps that are designed for the windows envirnment. 
No run command is needed on .pyw files, just doubleclick to launch.
Most libraries used are already part of the base python3 install package, and most tools are written with python 3.11

Please use 'pip install X' to install any missing libraries (replacing 'X' with the library name)
  Libraries may include:
    pandas
    polars
    csv
    os
    paramiko
    psutil
    sys
    xml
    random
    tkinter
    typing
    collections
    traceback
    datetime
    time
    pythonping
    threading
